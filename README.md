# AISA Mobile — Task 01

Controlled React Native + Expo UI shell extracted from the approved Crypto Demo mobile presentation.

## Commands

```bash
npm install
npm run typecheck
npm run web
```

## Scope

Task 01 contains only the native UI shell: Home, Profile, top bar, bottom navigation, menu and notifications, plus exact Assistant and Cart placeholders.

Not connected in this stage: Assistant integration, retailer catalog, cart logic, wallet/Phantom, Solana, Web3, backend/API, Android native project generation.
